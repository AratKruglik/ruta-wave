# App Icon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the "wave petals / play from waves" Rutawave icon as an Icon Composer `.icon` file that is part of the app build.

**Architecture:** A Python script generates the icon's SVG layers and `icon.json` from the geometry in the spec, writing them into `App/AppIcon.icon`. XcodeGen includes that folder as a resource (`wrapper.icon`). At build time actool turns it into `Assets.car` with Liquid Glass plus an `AppIcon.icns` fallback for macOS 14–15. No manual Icon Composer step is needed: a hand-written `icon.json` compiled and built cleanly in a spike on 2026-11-25 (Xcode 27.2, XcodeGen 2.47).

**Tech Stack:** Python 3 (stdlib only), Icon Composer `.icon` format, `xcrun actool`, XcodeGen, xcodebuild.

**Spec:** `docs/superpowers/specs/2026-11-25-app-icon-design.md`

## Global Constraints

- Canvas 1024 × 1024, centre (512, 512). Graphics are white only; the background comes from the `.icon` fill, not from an SVG.
- Fill: linear gradient from `#E8253F` (top) to `#9E0E24` (bottom), i.e. `srgb:0.90980,0.14510,0.24706,1.00000` → `srgb:0.61961,0.05490,0.14118,1.00000`.
- Rings, outer → inner: R = 300 / 225 / 150, a = 0.16 / 0.20 / 0.22, stroke = 16 / 20 / 24, opacity = 0.45 / 0.70 / 1.00, blend m = 0 / 0.5 / 1.
- Ring radius as a function of the angle φ: `r(φ) = R·(1 + a·((1−m)·cos 5(φ+π/2) + m·cos 3φ))`; screen coordinates (y down), so φ = 0 points right.
- Play: equilateral triangle, circumradius 66, pointing right, centroid exactly at (512, 512), sides bulged outward by 5 % of the side length (`sin(π·t)` profile), white fill plus a white stroke of 30 with round joins.
- Deployment target macOS 14.0; app icon name `AppIcon`.
- Not in scope: the name and trademark check and the copy review from #28.

## Review Focus

1. 16 px and 32 px (Finder list, notifications): the inner ring and the play must not merge into a solid blob. Checked visually in Task 2, Step 6.
2. The macOS 14–15 fallback: the `AppIcon.icns` that actool writes must show the gradient, the rings and the play, not a blank or grey plate. Checked in Task 1, Step 4.
3. Appearance modes on macOS 26+ (dark, tinted, clear): the icon must stay legible. Checked in Task 2, Step 6.
4. Regenerating the project (`xcodegen generate`) must keep the icon: `App/AppIcon.icon` must stay a single `wrapper.icon` file reference, not a group of loose SVGs. Checked in Task 2, Step 3.
5. A stale icon in the Dock or Finder after rebuilding is the LaunchServices cache, not a bug: re-register the app before judging. Noted in Task 2, Step 6.

- [ ] **Step 1: Write the self-check first** — `check()` in `Scripts/generate-app-icon.py`, run by `--check`:

```python
def check() -> None:
    with tempfile.TemporaryDirectory() as tmp:
        out = Path(tmp) / "AppIcon.icon"
        write_icon(out)
        cx, cy = centroid(play_points())
        assert abs(cx - 512) < 0.5 and abs(cy - 512) < 0.5, (cx, cy)
        for ring in RINGS:
            pts = ring_points(ring.R, ring.a, ring.m)
            assert all(40 <= c <= 984 for p in pts for c in p), ring
        for f in ["icon.json", *(f"Assets/{n}.svg" for n in LAYERS)]:
            assert (out / f).read_bytes() == (ICON_DIR / f).read_bytes(), f"{f} is stale: rerun the generator"
        subprocess.run(["xcrun", "actool", str(out), "--compile", tmp, "--platform", "macosx",
                        "--minimum-deployment-target", "14.0", "--app-icon", "AppIcon",
                        "--output-partial-info-plist", f"{tmp}/p.plist"], check=True, capture_output=True)
        assert (Path(tmp) / "AppIcon.icns").exists() and (Path(tmp) / "Assets.car").exists()
```

- [ ] **Step 3: Implement the generator**

- `RINGS`: three records `(name, R, a, m, stroke, opacity)` with the values from Global Constraints. `LAYERS = ["play", "ring-inner", "ring-middle", "ring-outer"]`. `ICON_DIR = repo root / "App/AppIcon.icon"`.
- `ring_points(R: float, a: float, m: float, n: int = 720) -> list[tuple[float, float]]`: the formula from Global Constraints, closed polygon.
- `play_points(r: float = 66, bulge: float = 0.05, per_side: int = 40) -> list[tuple[float, float]]`: vertices `(512−r/2, 512−r·√3/2)`, `(512+r, 512)`, `(512−r/2, 512+r·√3/2)`; each side is sampled and pushed outward along its normal by `L·bulge·sin(π·t)`.
- `centroid(points) -> tuple[float, float]`: the mean of the points (the shape is symmetric about y = 512, so this is enough for the assert).
- Each SVG has a `viewBox` of `0 0 1024 1024` and a transparent background. Ring layers: `<polygon fill="none" stroke="#fff" stroke-width=… stroke-opacity=… stroke-linejoin="round">`. Play layer: `fill="#fff" stroke="#fff" stroke-width="30" stroke-linejoin="round"`. Coordinates are printed with 1 decimal place, so the output is deterministic.
- `icon.json`: `fill.linear-gradient` with the two sRGB values; `groups` = `[{layers: [play]}, {layers: [ring-inner, ring-middle, ring-outer]}]` (first = frontmost); `supported-platforms: {"squares": ["macOS"]}`. Write it with `json.dumps(..., indent=2, sort_keys=True)` plus a trailing newline.
- `write_icon(dest: Path) -> None` writes everything; `main` with no arguments calls `write_icon(ICON_DIR)`.
