# PR: guest-mode (backlog 1.4)

Гілка `feature/guest-mode` → `develop`.

## Підсумок

- Без збереженої сесії застосунок стартує як гість, вікно входу не відкривається примусово.
- «Sign in» тепер необов'язкова кнопка: Cancel повертає до гостя, Sign out теж.
- `InnerTubeClient` вміє робити гостьові запити без `Cookie`, `Authorization` і `X-Goog-AuthUser`. `X-Goog-Visitor-Id` береться з останнього валідного `visitorData` і тримається лише в пам'яті.
- Для наступних етапів є одне правило «чи увійшов користувач»: `AuthSession.State.isSignedIn`.
