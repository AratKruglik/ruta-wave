# QA-звіт: InnerTube core (backlog 1.2)

## Фреймворк
Swift Testing (`@Suite`, `@Test`, `#expect`), `swift test` у пакетах, `xcodebuild build` для застосунку.

## Додані тести
- `Packages/InnerTube/Tests/InnerTubeTests/EdgeCaseTests.swift`, 23 тести в 4 suites:
  - `JSONValueEdgeTests` (5): скаляри верхнього рівня, порожні контейнери, рядки, що схожі на інші типи, негативний індекс і null, unicode, некоректний JSON.
  - `SAPISIDHashEdgeTests` (3): кожен вхід змінює дайджест, ts=0 і порожній/unicode SAPISID, незалежний вектор `shasum` для порожнього SAPISID.
  - `RequestEdgeTests` (8): User-Agent із Safari-токеном і Content-Type, SAPISID з доменом `youtube.com`, порожній список cookies, cookie з `expires == now` відкидається, майбутній термін зберігається, `X-Goog-AuthUser` дослівно, локаль лише з мовою (gl=US), `context` не перекривається тілом.
  - `ParsingEdgeTests` (7): нерозбірні `account_menu`, порожні thumbnails і неправильний тип url, порожні runs у handle, `isSelected` і byline відсутні, нечисловий/відсутній `authuser`, елемент без імені, сторонні payload-и.
- Наявні 17 тестів розробника лишились без змін. Фікстури синтетичні, без Keychain, WKWebView і мережі.

## Manual check (AC13) findings
- Під час «Add account» після кроку пароля Google редіректить main frame на `https://gds.google.com/web/landing`; хоста не було в `SignInRules.allowedHosts`, навігацію скасовувало (WebKit 102), і вікно входу зависало. Виправлено: `gds.google.com` додано до allowlist + тестовий випадок.
- Далі Google редіректить на регіональний `accounts.google.<ccTLD>/accounts/SetSID` (напр. `accounts.google.com.ua`); хост не був дозволений, вікно лишалося порожнім. Виправлено: allowlist доповнено шаблоном `accounts.google.[com.|co.]<cc>` (рівно 2 літери) + тести дозволених і lookalike-хостів.
- `account/accounts_list` (body requestType ACCOUNTS_LIST_REQUEST_TYPE_CHANNEL_SWITCHER, callCircumstance SWITCHING_USERS_FULL, контекст WEB_REMIX) на живому акаунті повертає HTTP success лише з `responseContext` і `selectText` (без `actions` і `accountItem`), тож акаунтів 0; список і перемикання винесено в backlog 1.3, а 1.2 показує лише активний акаунт.
