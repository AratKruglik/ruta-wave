# PR: innertube-core (backlog 1.2)

Гілка `feature/innertube-core` → `develop`. PR: https://github.com/AratKruglik/yt-music-mac/pull/3

## Підсумок

Пакет `InnerTube` отримав ядро клієнта:
- `JSONValue`;
- actor `InnerTubeClient` з контекстом `WEB_REMIX`;
- підпис `SAPISIDHASH`, перевірений тестом на незалежно обчисленому значенні;
- запит `account/account_menu`.

Застосунок показує екран акаунта з іменем, handle й аватаром. Кнопки Add account і Sign out лишились. Ручну перевірку AC13 на живому акаунті пройдено.

## Зміни за результатами ручної перевірки

- До allowlist входу додано `gds.google.com` і регіональні `accounts.google.<cc>`. Без них Add account зависав.
- `accounts_list` не повертає акаунтів, тому список і перемикання винесено в беклог 1.3.

## Тести

`xcodebuild build` проходить чисто. `swift test`: InnerTube 35, Auth 12, решта пакетів по 1 тесту, усі зелені.
